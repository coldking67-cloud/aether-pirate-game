# Aether Pirate Game — Godot workspace

Current focus: world-first milestone.

## What we are building first
- A good-looking Caribbean-inspired world
- Nations, pirate factions, smuggling faction, and freelance NPCs as data first
- A basic boat placeholder so the world can be sailed and judged

## Folders
- `world/` — geography, factions, settlements, hazards
- `assets/` — art and ship placeholders

## Open
- Engine choice: 2D/2.5D Godot is the current recommendation; revisit if 3D water/ships become the priority
- Exact art style: stylized readable world, not photoreal, for the first pass
