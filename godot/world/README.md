# Aether World — first milestone folder

This folder holds the starting world data for the Caribbean-inspired map.

## What exists now

- `caribbean_shallow.json` — placeholder geography: regions, nations, pirate factions, smuggling faction, settlements, nav points, and hazards.

## Design intent for the world-first milestone

- Readable stylized map first, detail later
- Caribbean shape as inspiration, not a literal copy
- Good-looking water, coastlines, hazards, and settlement anchors
- Basic boat placeholder acceptable just to judge scale and motion

## Next steps

- Turn the JSON into a readable world layout in-engine
- Add water/atmosphere first pass
- Place nav points and hazards
- Add a basic boat placeholder
- Decide 2D/2.5D vs 3D before heavier art investment
